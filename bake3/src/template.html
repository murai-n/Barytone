フィルムプロファイル焼き込みツール

Capture Oneのカメラプロファイルに、フィルムの色の特性を焼き込んだICCプロファイルを作ります。元のプロファイルの色を土台にするので、お使いのカメラに合ったフィルムの色になります。

選んだプロファイルは、このブラウザの中だけで処理されます。外部には送信されません。

1元にするプロファイルを選ぶ

Capture One が持っているカメラプロファイルのフォルダを選ぶと、カメラ名で探せます。

フォルダの場所

「フォルダを選択」を押すと、フォルダを開くダイアログが出ます。そこで次の場所を開いてください。

Mac

アプリ名は、Finder の「アプリケーション」にある名前の通りに選択してください。見つからないときはフレームワークを切り替えてください。
  1. ダイアログで command + shift + G を押します。
  2. 出てきた入力欄に、次のパスを貼り付けて return を押します。
  3. 「開く」を押します。

Windows

  1. ダイアログ上部のアドレス欄に、次のパスを貼り付けて Enter を押します。
  2. 「フォルダーの選択」を押します。

または、このエリア内にドラッグ＆ドロップ

    まだ何も選ばれていません

      例：Z5、EOS R5、X-T4。スペースで区切ると、すべての語を含むものだけが残ります。
      押すと選択、もう一度押すと解除です。別のカメラも続けて選ぶと、まとめて1つのZIPで作れます（8台まで。同じカメラは1つだけ）。
      Neutral や Standard のように、絵作りの入っていないものが編集しやすいためおすすめです。Portrait や Vivid のような演出済みのプロファイルを元にすると、その演出の上にフィルムの色が重なります。

        置き場所

        ZIPを展開してできる2つのフォルダを、それぞれ次の場所に移します。複数のカメラを選んだときは、カメラごとに同じ2つが並んでいます。

        ICC (カメラ名) の中身（ICCプロファイル）

        /Library/ColorSync/Profiles %LOCALAPPDATA%\CaptureOne\Color Profiles

        1 Film (カメラ名) フォルダごと（スタイル）

        ~/Library/Application Support/Capture One/Styles %LOCALAPPDATA%\CaptureOne\Styles50 Finder で command + shift + G を押し、貼り付けると開きます。 エクスプローラーのアドレス欄に貼り付けると開きます。Styles50 がない場合は Styles に入れてください。

        仕上がりの見本

        カラーチェッカーとグレーの階調を、それぞれのフィルムのモデルに通した色です。元のプロファイルの色は含まないため、実際の写真とは少し異なります。

        Capture One での使い方

        1. ダウンロードしたZIPファイルを展開します。ICC (カメラ名) と 1 Film (カメラ名) の2つのフォルダが入っています。
        2. ICC (カメラ名) フォルダの中身を、手順2に出ているICCプロファイルの置き場所に移します。
        3. 1 Film (カメラ名) フォルダをフォルダごと、手順2に出ているスタイルの置き場所に移します。Capture One のスタイル一覧に、このフォルダ名でまとまって並びます。中は Negative（カラーネガ）、Positive（リバーサル）、B&W（モノクロ）の3つに分かれています。
        4. Capture One を再起動します。
        5. 写真を開き、スタイルを適用します。ベース特性のICCプロファイルとカーブは、スタイルが自動で設定します。

        スタイルはプロファイルを名前で参照しています。ICCプロファイルを所定のフォルダに配置し再起動すると選択可能になります。

        リバーサルはコントラストが強いため、暗く感じたら露出を +0.3〜0.5 ほど上げてください。

        モノクロ（IHP5、KTX400 など）のプロファイルはネガの段階までで、それだけでは平坦な調子になります。キットの 3 Paper (B&W) にある印画紙スタイル（印画紙 4 種 × 号数 00〜5）を重ねて、焼きの調子を選んでください。見本は MGIV RC 2 号で焼いた場合です。
