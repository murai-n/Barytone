# Capture One: カーブは ICC の前か後か

テスターの報告（ポジの slide tone を一定倍しても、色によって明るさの上がり方が違う）から、
スタイルのカーブがフィルム ICC より前に効いている疑いがある。キットは「ICC → カーブ」の順を前提にしているので確かめる。

## 手順
1. 赤いもの（赤い服・花など）と青空や緑が入った写真を開く。
2. B&W のフィルムスタイル（例: `Film KTX400`、フィルターなし）を当てる。
3. `Order test - Red off (layer)` を当てる（赤チャンネルのカーブを 0 に潰すだけのレイヤー）。
4. 戻して、`Order test - Red off (base)`（同じカーブをレイヤーでなく本体に）でも試す。

## 読み方
| 見え方 | 意味 |
|---|---|
| 画面全体がシアンになる | カーブは ICC の **後**（キットの前提どおり） |
| モノクロのまま、赤いものが大きく暗くなる（シアンのフィルターを掛けたよう） | カーブは ICC の **前**（テスターの推定どおり。カーブはフィルムへの露光を変えている） |
| モノクロのまま、赤いものの明るさも変わらない | カーブは ICC の後だが、モノクロ扱いで色が捨てられている |

layer と base で結果が違えば、それも記録する。

## 2回目：チャートで数値を取る（赤いものだけが沈むか、全体が一様に沈むかを見分ける）

1. `order_test_chart.png` をモニターに全画面で表示し、部屋を暗くする。
2. ICC を作ったカメラで RAW で撮る。チャートが画面の大部分を占めるように。ピントを少し外すとモアレが出ない。
   露出は Grey 2 にスポット測光で合わせ、White が飛ばないこと（ヒストグラムの右端に届かない）を確認する。
3. Capture One で B&W のフィルムスタイル（`Film KTX400`、フィルターなし）を当てる。
4. 各パッチの L をカラーピッカーで読み、`order_test_sheet.csv` の「L* without」に書く。
5. `Order test - Red off (layer)` を足して、もう一度読む（「L* with」）。
6. 差を EV にする：EV = log2(Y_with / Y_without)、Y = ((L*+16)/116)^3。L* の差だけでも傾向はわかる。

## 読み方（予想値は sRGB で近似した計算値）
- **A（カーブが ICC の前）**：赤・橙・マゼンタ・明るい肌が −0.8〜−1.6EV と大きく沈み、緑・シアン・青・白はほぼ 0。
- **B（ICC → カーブ → 色を捨てる）**：全パッチが同じだけ沈む（計算では約 −0.5EV。値そのものより「全部同じ」が目印）。
